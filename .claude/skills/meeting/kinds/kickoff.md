# Kickoff

Defines the development: no milestone in `timeline.md`. No preparation file: the chief engineer interviews the owner, one topic at a time, and reads drafts back.

## Agenda

1. **Needs:** what the projects using PLM need next (`improvements.md`, open `type:backlog` issues), generalised.
2. **Milestones:** usually releases; per milestone its features as entry conditions, each with a *done when*, and its budget in usage windows.
3. **Big features:** those needing a feature review before they are built (`feature.md`, When).
4. **Standing directions.**

## Outcome

`timeline.md` with all milestones, the first one active with its entry conditions and budget; one `type:feature` issue per feature; GitHub milestones; standing directions in `decisions.md`; `handover.md`.
