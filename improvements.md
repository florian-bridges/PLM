# PLM improvements

Open topics are GitHub issues: https://github.com/florian-bridges/PLM/issues. Earlier entries and their decisions: `git show 17e628f:improvements.md`.

A project that does not open issues itself appends an entry here; the product owner moves it to an issue and deletes it here. Format:

```
## <short title>
*Found:* <date>, <product repository>, <agent or person>
*Observed:* what happened, with the command
*Impact:* what it costs or risks in practice
*Workaround:* what is done meanwhile, if anything
*Proposal:* a possible change (optional)
```
